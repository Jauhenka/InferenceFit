# InferenceFit 0.2.3

InferenceFit 0.2.3 adds small named profiles for three decentralized inference provider gateways:
Chutes, Morpheus, and Nosana. They reuse the existing non-streaming OpenAI-compatible adapter and
the public `benchmark()` path. Serialized `schema_version: "0.1"` is unchanged.

```bash
pip install inferencefit==0.2.3
```

| Provider | Hosted API base | Credential fallback | Model catalog |
| --- | --- | --- | --- |
| `chutes` | `https://llm.chutes.ai/v1` | `CHUTES_API_KEY` | Public `/models` |
| `morpheus` | `https://api.mor.org/api/v1` | `MORPHEUS_API_KEY` | Authenticated active `/models` |
| `nosana` | `https://inference.nosana.com/v1` | `NOSANA_API_KEY` | Authenticated `/models` lists models currently served |

Supply the provider's current native model ID; the release has no default model or runtime
discovery. An explicit `credential_ref` still takes precedence over the fallback, and a named
provider's explicit `base_url` still selects the shared chat path. Resolved secret values never
enter persisted artifacts; opaque references retain their existing persistence behavior.

Chutes' hosted API runs on Chutes/Bittensor infrastructure. Morpheus uses its managed API gateway
backed by the inference marketplace; that gateway does not make the complete request path
cryptographically attested. Nosana's hosted LLM API runs on Nosana GPUs and availability changes
with currently serving machines. These profiles do not add direct node, wallet, staking, token,
deployment, or billing integrations.

**Unknown cost stays unknown.** Chutes and Nosana expose changing model catalog prices, while
Morpheus publishes a pricing page; InferenceFit does not use those as authoritative per-request
charges or scrape them. Configured `pricing` plus complete token usage can estimate cost.
The shared adapter keeps safe HTTP errors and rejects `parameters.stream`, `model`, and `messages`
before HTTP. Nosana model-not-found can mean a model is not currently served; no broad paid retry
change is introduced.
For example, a Chutes account without enough credits can return HTTP 402. The shared HTTP
normalizer reports this as a safe, non-retryable `http` error; replenish access before rerunning.

See the [Chutes](../../examples/chutes/README.md), [Morpheus](../../examples/morpheus/README.md),
and [Nosana](../../examples/nosana/README.md) examples. Opt-in live smoke tests use matching
keys and one tiny non-streaming public benchmark. Chutes may use one public catalog request to
select an inexpensive text model or an explicit `CHUTES_TEST_MODEL`. Morpheus needs
`MORPHEUS_TEST_MODEL` to avoid guessing price. Nosana needs `NOSANA_TEST_MODEL`; one authenticated
catalog read confirms it is currently served because the catalog does not reliably identify
chat-ready models. Ordinary tests,
wheel/sdist smoke, presets, the Agent Skill, fixture, and `provider: custom` remain offline.

The deprecated unknown-provider plus explicit-`base_url` route remains backward compatibility;
new arbitrary OpenAI-compatible endpoints use `provider: custom`. See [0.2.2 notes](0.2.2.md)
for the generic-provider contract.
