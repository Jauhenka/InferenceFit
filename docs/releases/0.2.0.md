# InferenceFit 0.2.0

This release adds OpenRouter, Gemini, and OpenAI evaluation paths to the local-first benchmark
workflow. Fireworks, DeepSeek, deterministic fixtures, Ollama/vLLM, and explicit compatible
endpoints remain supported. Python 3.11 or newer is required.

```bash
pip install inferencefit==0.2.0
```

## Provider behavior

- OpenRouter uses chat completions, requests metadata, and records valid reported request cost
  and serving backend. Its credential fallback is exactly `OPEN_ROUTER_API_KEY`.
- Gemini uses Google's OpenAI-compatible chat completions endpoint with `GEMINI_API_KEY`.
- OpenAI uses the native Responses API with `OPENAI_API_KEY`, stateless input, and `store: false`.
  It normalizes `max_tokens` or `max_completion_tokens` to `max_output_tokens` and rejects
  conflicting limits or reserved request fields.
- An explicit candidate `base_url` selects generic chat completions for custom or local servers.

Opaque `credential_ref` environment variables take precedence over provider fallback keys.
Run artifacts omit credential values. Model IDs and supported parameters depend on the provider,
model, and account; the bundled smoke defaults may need updating for your environment. Some
OpenAI models reject `temperature`. No live validation claims are made for this release preparation.

## Contracts and cost

Serialized `schema_version: "0.1"` is unchanged. The optional observation keys `provider`,
`model`, `provider_backend`, `cost_source`, and `usage.total_tokens` default to null when absent,
so older observations remain readable and compatible runs remain resumable. Strict older readers
may need to accept these additional keys. See [serialized contracts](../contracts.md) for the
compatibility details.

Valid reported request cost takes precedence over configured token pricing. Otherwise, missing
usage or prices leave cost unknown. This release does not fetch price catalogs or reconcile
invoices. Existing quality, reliability, latency, constraints, ranking, and fallback semantics
remain in place.

## Try it

From the source checkout, the offline fixture quick start requires no credentials:

```bash
inferencefit validate examples/basic/eval.yaml
inferencefit benchmark examples/basic/eval.yaml
```

Live requests spend provider credits and must be explicitly selected with the matching key set:

```bash
# OPEN_ROUTER_API_KEY
inferencefit benchmark examples/lead_semantic_units/eval.openrouter.smoke.yaml
# GEMINI_API_KEY
inferencefit benchmark examples/lead_semantic_units/eval.gemini.smoke.yaml
# OPENAI_API_KEY
inferencefit benchmark examples/lead_semantic_units/eval.openai.smoke.yaml
python -m pytest tests/test_provider_live.py -m provider_live -q
```

Live pytest checks skip independently when their own provider key is absent. Override models with
`OPEN_ROUTER_TEST_MODEL`, `GEMINI_TEST_MODEL`, or `OPENAI_TEST_MODEL`. The
[examples index](../../examples/README.md) and [README](../../README.md) include the preserved
provider paths and minimal candidate configurations.

## Release safety and scope

Package metadata, runtime version, API health/OpenAPI, and manifests share the maintained version
source. CI and TestPyPI artifact checks expect 0.2.0. Release gates build once, check metadata,
audit wheel/sdist contents, and smoke-test isolated installs before any publishing workflow.
The distribution audit rejects assignments to the exact new credential names while allowing
documented placeholders and retaining the existing key, archive-path, and resource protections.

Evaluation remains non-streaming and text-based, routing is limited to one two-stage fallback,
and the daemon is for trusted localhost use. There is no hosted service, account system, browser
UI, traffic proxy, distributed execution, learned routing, model training, or non-Python SDK.
Historical [0.1.0 notes](0.1.0.md) and fixtures are retained.
