# InferenceFit 0.2.1

InferenceFit 0.2.1 is an Agent UX and workload-presets release. It keeps the local-first benchmark
core and the multi-provider surface from 0.2.0 while making a correct first evaluation easier to
start for both humans and coding agents.

```bash
pip install inferencefit==0.2.1
```

## Workload presets

The release ships exactly three canonical starter projects:

- `coding` for code generation and transformation with deterministic checks;
- `document-processing` for a deterministic classification starting shape and guidance for QA,
  summarization, synthesis, and long-input work; and
- `structured-extraction` for schema-checked typed JSON extraction.

Use `inferencefit presets` to list them and
`inferencefit init --preset <id> <destination>` to create a project. Initialization has strict
non-overwrite semantics: the destination and its parent are checked before copying, and an existing
file, directory, or dangling link is never replaced. Every project contains exactly two synthetic
cases, one offline fixture candidate, deterministic validators, and one repetition.

Replace the sample cases with representative production examples before using the benchmark for
model-selection decisions. The sample success is a plumbing check, not evidence that a model is
appropriate for production.

## Portable Agent Skill

The distribution includes an Agent Skills-compatible `inferencefit` skill with focused references
for presets, validators, and result interpretation. `inferencefit skill path` prints the absolute
installed directory so users can copy or link it using their agent's supported mechanism. The
skill applies the same public validate and benchmark workflow; it is not another engine.

The skill starts live exploration at no more than three candidates, five cases, and one repetition,
requires a pre-run request and cost summary, treats unknown cost as unknown, and prohibits exposing
credential values or inventing ground truth.

## Packaging and compatibility

Wheel and source-distribution audits now require all twelve preset files and all four skill files.
Installed-artifact smoke tests list presets, initialize and benchmark structured extraction offline,
and verify the packaged skill path outside the source checkout.

Serialized `schema_version: "0.1"` is unchanged. Existing provider integrations, credentials,
validators, artifact formats, CLI validate/benchmark behavior, Python API, and benchmark engine
remain compatible with 0.2.0.

## Out of scope

This release does not add or redesign a provider, benchmark engine, serialized schema, semantic
judge, provider/model ranking, hosted service, or universal `skill install` command. It does not
claim that fixture results or a preset identify a universally superior model. Existing limitations
around non-streaming text evaluation, one two-stage fallback, and trusted local Python validators
remain.

See the historical [0.2.0 notes](0.2.0.md) and [0.1.0 notes](0.1.0.md).
